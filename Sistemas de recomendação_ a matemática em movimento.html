Sistemas de recomendação em movimento

Cinco abordagens, um mesmo conjunto de dados: 5 usuários, 6 filmes, notas de 1 a 5. Cada demonstração roda sozinha e acende, à esquerda, a equação da etapa que está sendo executada.

\(R\in\mathbb{R}^{m\times n}\) é a matriz de notas, quase toda vazia. \(\Omega=\{(u,i): r_{ui}\ \text{observado}\}\).

Recomendar é estimar \(\hl{\hat r_{ui}}\) para todo \((u,i)\notin\Omega\) e ordenar os itens por esse valor.

01

Filtragem colaborativa (CF)

Usa apenas \(R\). Hipótese: quem concordou no passado concorda no futuro. A nota prevista de Ana para um filme vem dos vizinhos mais parecidos com ela, corrigida pela tendência de cada um a dar notas altas ou baixas.

  1. 1. Média de cada usuário
    \[\hl{\bar r_u}=\frac{1}{|I_u|}\sum_{i\in I_u} r_{ui}\]
  2. 2. Similaridade de Pearson nos itens co-avaliados \(I_{uv}\)
    \[\hl{\mathrm{sim}(u,v)}=\frac{\sum_{j\in I_{uv}}(r_{uj}-\bar r_u)(r_{vj}-\bar r_v)}{\sqrt{\sum_{j\in I_{uv}}(r_{uj}-\bar r_u)^2}\,\sqrt{\sum_{j\in I_{uv}}(r_{vj}-\bar r_v)^2}}\]
  3. 3. Vizinhança: os \(k\) mais similares que avaliaram \(i\)
    \[\hl{N_k(u;i)}=\text{top-}k\ \{v: (v,i)\in\Omega\}\ \text{por}\ \mathrm{sim}(u,v)\]
  4. 4. Predição: média + desvios ponderados
    \[\hl{\hat r_{ui}}=\bar r_u+\frac{\sum_{v\in N_k}\mathrm{sim}(u,v)\,(r_{vi}-\bar r_v)}{\sum_{v\in N_k}|\mathrm{sim}(u,v)|}\]

Limite: um filme que ninguém avaliou não tem coluna preenchida, logo não tem vizinhos. É o cold start de item.

02

Filtragem por conteúdo (CBF)

Ignora os outros usuários. Cada filme vira um vetor de atributos \(x_i\) (aqui, gêneros) e cada usuário vira um perfil \(p_u\) no mesmo espaço, somando os filmes que viu com peso positivo se gostou e negativo se não gostou.

  1. 1. Itens como vetores normalizados
    \[\hl{\tilde x_i}=\frac{x_i}{\lVert x_i\rVert},\qquad x_i\in\{0,1\}^{|G|}\]
  2. 2. Perfil do usuário
    \[\hl{p_u}=\sum_{i\in I_u}(r_{ui}-\bar r_u)\,\tilde x_i\]
  3. 3. Score por cosseno
    \[\hl{s(u,i)}=\cos(p_u,\tilde x_i)=\frac{p_u^{\top}\tilde x_i}{\lVert p_u\rVert}\]
  4. 4. Ranking dos não vistos
    \[\mathrm{rec}(u)=\operatorname{argsort}_{\,i\notin I_u}\ \hl{s(u,i)}\]

Perfil \(p_{\text{Ana}}\) por gênero

03

Fatoração de matrizes (MF)

CF baseada em modelo. Supõe que \(R\) tem posto baixo: cada usuário e cada item são descritos por \(k\) fatores latentes, e a nota é o produto interno entre eles. Aqui \(k=2\), então dá para ver usuários e filmes se organizando num plano enquanto o SGD minimiza o erro.

  1. 1. Modelo
    \[\hl{\hat r_{ui}}=\mu+b_u+b_i+p_u^{\top}q_i,\qquad p_u,q_i\in\mathbb{R}^{k}\]
  2. 2. Perda regularizada, só sobre \(\Omega\)
    \[\hl{\mathcal{L}}=\sum_{(u,i)\in\Omega}(r_{ui}-\hat r_{ui})^2+\lambda\big(b_u^2+b_i^2+\lVert p_u\rVert^2+\lVert q_i\rVert^2\big)\]
  3. 3. SGD: uma amostra \((u,i)\in\Omega\) por vez
    \[\hl{e_{ui}}=r_{ui}-\hat r_{ui}\]\[\begin{aligned}b_u&\leftarrow b_u+\eta\,(e_{ui}-\lambda b_u)\\ b_i&\leftarrow b_i+\eta\,(e_{ui}-\lambda b_i)\\ p_u&\leftarrow p_u+\eta\,(e_{ui}\,q_i-\lambda p_u)\\ q_i&\leftarrow q_i+\eta\,(e_{ui}\,p_u-\lambda q_i)\end{aligned}\]
  4. 4. Completar a matriz
    \[\hl{\hat R}=PQ^{\top}+\text{vieses},\qquad \operatorname{posto}(PQ^{\top})\le k\]

04

Recomendação sensível ao contexto

A mesma pessoa quer coisas diferentes em situações diferentes. O contexto \(c\) (hora, companhia, dispositivo) vira uma terceira dimensão: a matriz vira um tensor, e o contexto ganha seu próprio vetor latente \(w_c\) que reescala os fatores. A alternativa mais simples, pré-filtragem, treina uma MF separada em cada fatia \(R_{::c}\), ao custo de dividir os dados.

  1. 1. Dados em tensor
    \[\hl{R}\in\mathbb{R}^{m\times n\times |C|},\qquad r_{uic}\]
  2. 2. Fatoração CP (três vias)
    \[\hl{\hat r_{uic}}=\sum_{f=1}^{k}p_{uf}\,q_{if}\,w_{cf}=\big\langle p_u,\ q_i\odot w_c\big\rangle\]
  3. 3. Ranking condicionado ao contexto
    \[\mathrm{rec}(u,c)=\operatorname{argsort}_{\,i}\ \hl{\hat r_{uic}}\]

\(p_{\text{Ana}}=(1{,}0;\ 0{,}5;\ 0{,}6)\). Os rótulos f₁ ação, f₂ infantil, f₃ emoção são ilustrativos: fatores aprendidos não têm nome.

05

Modelo híbrido (CF + CBF)

CF é forte com histórico e inútil sem ele. CBF funciona desde a primeira interação, mas só recomenda o que se parece com o que já foi visto. O híbrido ponderado desloca o peso de um para o outro conforme o usuário acumula interações \(n_u\).

  1. 1. Peso adaptativo (\(\beta=5\))
    \[\hl{\alpha_u}=\frac{n_u}{n_u+\beta}\]
  2. 2. Combinação convexa, scores em \([0,1]\)
    \[\hl{\hat r_{ui}}=\alpha_u\,\hat r^{\,\mathrm{CF}}_{ui}+(1-\alpha_u)\,\hat r^{\,\mathrm{CBF}}_{ui}\]
Híbrido dentro do modelo (estilo LightFM): o embedding do item é a soma dos embeddings dos seus atributos, \[q_i=\sum_{g\in G(i)}e_g,\qquad \hat r_{ui}=p_u^{\top}q_i\] Um filme novo já nasce com \(q_i\), resolvendo o cold start de item dentro da própria MF.
